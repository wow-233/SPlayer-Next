一起听逻辑补齐并适配到当前播放器：

- 操作完成后丢弃此前发出的状态查询；退出、换房及停止服务后使旧操作响应失效
- 恢复约 2 秒的本地状态刷新，批量推歌在退出或换房后停止
- 清除过期操作错误，插件同步失败通过现有错误区域显示
- 从响应式歌曲对象取原始数据传给 IPC
- 恢复播放先通过插件对齐官方房间进度
- 本机解码、音源失效交给房间插件重试，不触发全房间下一首，也不清掉房间队列

新版官方插件宿主已直接传输业务结果，旧版用于避免歌手资料截断的深度清洗补丁不再照搬。

## 更新与交付边界

这只是准备好私有分支的更新来源：需要以后在该仓库发布包含对应更新清单和安装包的 Release 才能在线更新。未发布时检查失败或没有新版均不代表已经建立可用的更新服务；不会退回官方源。此前插件仓库中的旧安装包不作为本次自动更新来源。

插件继续使用 `1.3.5`，`@apiLevel 4` 可在当前扩展宿主 API 5 中加载；官方原版缺少本插件需要的 `netease` 权限及多人房间接口，不能仅导入插件替代宿主适配。

本次保留当前 Vue 页面、CSS、图标、布局、配色和氛围屏，不创建 PR、不 push、不发布 Release。所有修改留在当前分支工作区供查收。
